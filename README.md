# Leads — Painel Comercial

Aplicação estática hospedada no GitHub Pages e conectada ao Supabase.

## Acesso

- Produção: https://drjfalcao-bot.github.io/leads/
- Usuário autorizado: `dr.jfalcao@gmail.com`

## Recursos

- Login exclusivo por e-mail e senha.
- Visão geral da base.
- Filtros por estado, status, responsável e qualidade cadastral.
- Empresas com paginação no servidor.
- Edição de status operacional, prioridade e observações.
- Cadastro e edição de contatos.
- Associação de contatos às empresas.
- Visualização por UF.
- Tema claro/escuro.
- Troca de senha.

## Dados

A aplicação usa uma fotografia estática da base HubSpot de 23/07/2026. Não existe sincronização automática.
